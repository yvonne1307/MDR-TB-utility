# MDR-TB-utility
This repository contains the R code used for the statistical analyses of health utility among patients with multidrug-resistant tuberculosis (MDR-TB).

## Repository structure

The `Code` folder contains two R scripts:

### 1. `01_univariate_analysis_and_distribution_figure.R`

This script is used for:
- descriptive analysis of health utility values;
- univariate analyses; and
- visualization of the distribution of health utility values.

### 2. `02_tobit_and_sensitivity_analysis.R`

This script is used for:
- Tobit regression analysis; and
- sensitivity analyses.

## Software

The analyses were conducted using R.

## Data availability

The individual-level data used in this study are not publicly available due to privacy and confidentiality considerations. The R code used for the statistical analyses is provided in this repository to support transparency and reproducibility.
